1. **"Sports glossary"** — Current #1 result is a farming almanac. Embarrassingly weak SERP.
2. **Trending sports** (pickleball, padel, F1) — Zero quality competition below position 1
3. **Quick-answer format** — No competitor uses structured data for featured snippets
4. **Visual rule explainers** — No competitor has diagrams, field layouts, or interactive tools
5. **Scoring system comparisons** — No cross-sport scoring content exists
6. **Rule comparison pages** — "Basketball vs handball" type content has zero dedicated results
7. **PWA/offline access** — No competitor has an app-like experience
