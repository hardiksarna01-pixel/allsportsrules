## Social Media Strategy

### Platform Priorities

| Platform | Content Type | Frequency | Audience |
|---|---|---|---|
| **YouTube** | Rule explainer shorts (60-90s), "Sport in 5 Min" | 3x/week | Search learners |
| **TikTok** | "Did You Know" facts, quiz clips, ref calls | 5x/week | Gen Z fans |
| **Instagram** | Infographic carousels, field diagrams, Reels | 4x/week | Millennials |
| **X/Twitter** | Live event rule clarifications, daily terms | Daily + events | Hardcore fans |

### Content Calendar Rules
1. **Event-reactive**: When controversial call happens live → immediately post rule explainer
2. **Daily "Term of the Day"**: 75 glossary terms = 75 days of content pre-written
3. **Weekly quiz challenge**: Share quiz from the app, encourage friends to beat scores
4. **Pre-event countdowns**: Build content around upcoming events from our 189-event calendar
5. **"Settle This" engagement**: Post debatable rule scenarios, let audience vote

### YouTube Series
- "Sport Explained in 5 Minutes" (mirrors our 5-min guides)
- "Is It a Foul?" (clip breakdowns using ref scenarios from mini games)
- "Sport A vs Sport B" (drives comparison page traffic)
- "Most Confusing Rules" (compilation format, high shareability)

### TikTok Series
- Quick rule facts from glossary (75 ready-made scripts)
- "Rate This Ref Decision" (uses game scenario data)
- Quiz clips from the quiz feature
- "Things you didn't know about [sport]" from facts arrays

- Guest posts on Breakthrough Basketball, cricketcounsel.com, similar niche sites

### Tier 2: Content Marketing
- Infographic link bait: field dimension comparison charts, scoring system visuals

- University sports program resource pages

### Tier 3: Community
- Reddit engagement: r/sports, r/soccer, r/cricket, r/formula1 — answer questions with links
- Quora answers for sports rules questions
- Sports forum participation

## Risk Mitigation

| Risk | Mitigation |
|---|---|
| Google algorithm update | Diversify: social, direct, email, PWA installs |
| Content copying | Canonical tags, DMCA registration, unique interactive features can't be copied |
| Competitor response | Move fast — they're slow, ad-dependent, technically outdated |
| Technical failure | Regular Lighthouse audits, uptime monitoring, error boundary in React |
| Content accuracy | Source rules from official governing bodies, date-stamp updates |
